# Delta review 2 (delta2.md): what was done

- **N1 (major), done as the review's fix.** `checkBoss`: `maia = brain && !share && host's maiaReady`. With the host's Maia not loaded,
  no brain goes to anyone (`sendBossRequest`: his own move carries it only when `bossCheck.maia`), so both devices play the seeded
  Stockfish move, any seeded device can check, and nobody's `by` is heard. Since a request's brain no longer reaches a host whose Maia
  isn't loaded, that host is sent the `bossBrain` message each such move instead (a new host after a timeout still loads Maia). The
  app withdraws `maiaReady` when its Maia fails: `HumanUciEngine.onFail`, `{ t: "maiaReady", off: true }`; the server deletes it.
  Proof P2 turned around: `delta2-review-fable-b3.test.ts` (any phone checks, no brain, the better move plays 5 of 5, vouched), plus
  a test of the host's Maia loading and then failing.
- **N2 (major), done as the review's fix.** `playChecked`: once two answers settle the move, its extras are the host's own answer's
  when it played that move; otherwise, on a turn with extras and the host connected, the host is re-asked (`bossCheck.reask`; the
  whole request, `allowed: [move]`, the same seed, no long pull, no brain) and only its answer for that move counts; with no answer
  in `checkMs()` (4 s plus the extras' allowance) the settled answer's extras play. Covers the same move's "fuller extras" too
  (two checkers, the host late). A move the turn doesn't play as-is (Wrangler's long pull) isn't re-asked. Proof P1 turned around
  for both brains, plus the same-move case; the old D2 test now checks the timeout fallback.
- **N3 (minor), done.** The `solo` path was dead: removed `SquadsReward.solo`, writeReward's `cap: "solo"` for it, and its own
  test; fixed the comments at `SquadsRecord.unvouched` and the one-party note in squads-lobby.ts.
- **N4 (minor), done.** One run of `elo-draw.ts` at the table's T (the script now prints that T and the draw's exact mean at it).
  A real seeded move was 24% under UCI's at 1600 and 21% over at 2800 (2200, 2500 within 6%), so the table changed: pooling both
  runs' real moves against their own UCI through each run's exact-mean slope gives 1600 1.25 and 2800 1.05 (2200, 2500 stay
  1.25). The head-to-head check cuts less at 2800 (real/exact 0.94-0.98 vs about 0.83 elsewhere), which the old derivation's
  single 0.866 missed. The runs' own noise is about ±15% a point; `reports/elo-draw.md` says so.
- **N5 (minor), done.** `useBrain(…, request)`: a request's brain sets `bossPlan` only if none (`??=`); the `bossBrain` message's
  plan (with its share) stays.
