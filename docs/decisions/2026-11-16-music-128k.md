# The music at 128 kbps (Nov 16, 2026)

**Eric:** "128 is fine for the game. But we wanna keep the lossless files tho for YouTube" (the masters aren't in the repo; not added).

- Every file in `packages/app/public/music/` re-encoded from its 192 kbps MP3 to stereo CBR 128 kbps, 48 kHz (`ffmpeg -c:a libmp3lame -b:a 128k`):
  67.5 MB -> 45.0 MB. The 192 kbps files stay reachable at tag `music-192k` (main at b3bd995).
- **Call: re-encode rather than re-render from the songs.** The brief asked for it; the check below shows it moves nothing. Each new file
  decodes to exactly the old's sample count, carries the same encoder delay (1105 samples, which ffmpeg and browsers trim), and
  cross-correlates with the old at offset 0, over the first 20 s and in 4096-sample windows at `pad` and `pad + loopSeconds` (intros: start
  and `introSeconds`; town solos: start and `seconds`). `pad` unchanged.
