# End screen sounds: listening demo (Nov 20)

Recorded from the page's own sound output (the real `sound.ts`), all files at one gain.

| File | When it plays | What it is |
| --- | --- | --- |
| `level-up.mp3` | A level reached (end screen, auto chess, a finished quest) | Steel pan: G5 C6 E6 G6 quick run, then a C6 E6 G6 C7 chord |
| `fill-end-note.mp3` | The XP bar stops filling | One soft steel pan G6 |
| `fill-100xp.mp3` | The bar filling for a 100 XP game | Pings climb a little (about half the way), then the last note |
| `fill-500xp.mp3` | The bar filling for a 500 XP game (2.8 s) | Pings rise C6 to A6, hold about a second, then the last note |
| `end-screen-100xp.mp3` | The real end screen after a solo boss win, +100 XP | Count-up (an octave down), landing, fill, last note, quest tick |
| `end-screen-350xp-with-level-up.mp3` | The same, +350 XP (the most one game pays without a bonus), crossing a level | Count-up, landing, fill, level-up, fill, last note, quest tick |
