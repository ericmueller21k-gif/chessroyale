# Town guard: the night roam recorded whole (`?report=120`)

**Cause.** The night loading-screen guard (`e2e/town-street.spec.ts:428`, added by #969) failed on main's #969 merge run (45771441684), on #973 twice (45791252709, 45795042926) and on #974 (45797983484): Done greyed at line 493. The report hadn't stuck at "wait". It had **finished**: each kept report reads "Report ready", 80 to 107 frames in 30.2 s, 3 to 4 fps, 0 painted, 0 uploads. The town caps a frame's step at 0.1 s (`Town.tsx`, `dt = Math.min(0.1, …)`), so at the 3 to 4 fps of a CI runner drawing two software-WebGL towns at once (the shard's other worker runs the desktop town tests at the same time) every walk takes about 2.5 times as long. The roam took 38 to 44 s, past the report's fixed 30 s run: the run ended itself and Done went grey. Alone it takes about 23 s, which is why it passed on faster shards and locally. It isn't tied to any branch: Chandy's PR changes nothing in the town (the built Town chunk is byte-identical to main's).

**Reproduced** in CI's image (`mcr.microsoft.com/playwright:v1.56.1-noble`): the guard alone passed (roam 23 s, 12 fps). With a second container running `town-street.spec.ts --project desktop` at the same time it **failed 2/2** the same way (roam 38 to 40 s, 4 fps, report "done" before Done).

**Fix.** `?report=S` sets the report's run length (`frame-report.ts` `reportMs`: 5 to 300 s; plain `?report` stays 30 s, so Eric's report is unchanged). The run's frame arrays are sized for it. The guard opens `/town?sky=night&crowd=12&report=120` and checks the run is still recording as it presses Done, so every frame of the roam is checked, and an overrun would say so plainly. The guard isn't loosened and there's no retry.

**Proof.** In CI's image, with the desktop town tests looping in a second container the whole time: `--repeat-each 10`, **10/10 passed** (9.3 min). Unit tests (`town-frame-report.test.ts`, 17 passed) and `npm run typecheck` pass.

**Player-visible:** none (`?report=S` is a new optional diagnostic length).

**Checks changed (old → new):**
- `e2e/town-street.spec.ts` "the town's loading screen…": opens `?report` → `?report=120`; new check before each Done: "still recording as the roam ends (all of it in the run)". No check removed or loosened.
- `packages/app/test/town-frame-report.test.ts`: new "`?report=S`" case (parsing, bounds, a 120 s run that doesn't end early).
