## The town never shows an old version (Eric's standing rule, Nov 13)

Eric saw the old Canvas 2D town on his iPhone (Nov 13, as admin). The street town's WebGL context lost twice in a minute, or not back in 5 s, reloaded the page at `/town?street=off`, which is the old town. iOS drops WebGL when the app goes to the background, so two app switches could do it.

**What changed**
- `?street=off` is gone completely, for everyone. No e2e needed it. No other switch opens the old town for an admin.
- A context lost while the page is hidden doesn't count. It gets 5 s once the page shows again (`town/gl-fail.ts` `lossWatch`).
- A context that comes back is fine, however often. The "lost twice in a minute" rule is gone.
- A context not back, or WebGL failing to start on a device that has WebGL 2 (no context, or the shader fails): the street town reloads once at `/town` with the same query.
- If it fails again within 2 minutes of that reload: **"The town didn't load. Please retry."** with a **Retry** button, nothing else. The reload time is kept in session storage; if there's no storage it shows the message straight away, so it can't loop.
- No WebGL 2 at all: **"Chess Town can't run on this device."** No button and no reload, since neither can help.
- Both messages use the loading card's look, over the whole town box (`.town-broken`).
- Reporting: still once per page (`TOWN_GL_FALLBACK`, counted in the health view).
  - `no-webgl2`: "can't run" shown.
  - `no-context`, `shader`, `not-back`: the page reloaded.
  - New `retry`: "didn't load" shown.
  - `lost-twice` stays in the list so the week's counts still read it; it's no longer raised.
  - The `/admin/ops` and `ops:report` wording changed to match.
- **New standing rule** in `docs/rules/eric.md`: "The town never shows an old version". Guarded by `packages/app/test/town-gl-fail.test.ts` and the two e2e tests below.

**What of the old Canvas 2D town players can still reach**
- Admins: nothing. No fallback and no switch.
- **Every non-admin, and guests: all of it.** `STREET_TOWN` is still admin-only (`admin-town.ts`), so today's Canvas 2D town is everyone else's town, as before this PR. Getting this to "nothing" means making the street town everyone's. That changes what every player sees and reworks about 8 of the 13 town-related e2e specs, which test today's town as a non-admin. The director's call (Nov 13): not in this PR. **Follow-up: "street for everyone", its own full-lane PR by a fresh helper.**
- That's also why the old town's code stays.
