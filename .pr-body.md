## Squads: no opening that starts in check

Eric, Nov 25 ("yes drop it"), after a Pairs board began from the Steinitz Gambit (1.e4 e5 2.Nc3 Nc6 3.f4 exf4 4.d4 Qh4+),
where White's first move is forced.

**What changed**
- `squadsOpenings(library)` (packages/chess/src/squads/match.ts): the lines a Squads board can start from, i.e. usable at
  `openingMoves` (4) per side and not leaving the side to move in check. `drawOpenings` now picks from it. Still seeded and
  deterministic (the same seed draws the same boards; not the same ones as before the filter, since the pool changed).
  `data/openings.json` is untouched.
- Dropped at 4 moves: **Vienna Gambit, with Max Lange Defense: Steinitz Gambit** (classic) and **Queen's Pawn Game: Modern
  Defense** (unusual, which Squads never draws anyway). Left: 101 usable lines, 31 classic families; a match needs at
  most 2 openings (Relay's 3 boards), so plenty.

**Player-visible:** Squads Random/One opening boards never start with the side to move in check.

**Solo / Classic / Crowd / raids (not changed, flagged):** `runner.ts` draws from the same library with `pickOpenings`
and can start in check too: at the default 4 moves (solo/Classic) the Steinitz Gambit is drawable; at 5 moves (raids,
or a Crowd Random opening set to 5) six lines start in check (Nimzo-Indian: Noa and Kmoch, Queen's Indian: Capablanca,
Scotch Game: Horwitz Attack, plus two unusual ones); other lengths have one to three each (Scotch Game at 6 moves has 2
legal moves). Same one-line filter would fix it there, left for the director since Eric answered for Squads.

**Lane:** targeted (Squads draw logic). Ran: `npm run typecheck`, `vitest packages/chess` and the Squads + server tests.

**Checks changed (old → new):** none changed or removed; added one to `packages/chess/test/squads-match.test.ts`
("no opening start leaves the side to move in check": the Steinitz line excluded, every pool start not in check, 200
seeded draws not in check, more than 20 classic families left).

Decision: `docs/decisions/2026-11-25-squads-no-check-starts.md`; area page `docs/areas/squads.md` updated.
