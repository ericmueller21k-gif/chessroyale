**For the director / Eric's OK (a quality gate):**
- **CI keeps the trace of the run that passed.** `e2e.yml` runs `--trace on-first-retry`, so a retry-pass's artifact holds the passing retry; the failed attempt leaves only its error-context snapshot. That's why fairplay:65's cause couldn't be found in rounds 2 and 3. Proposal: `--trace retain-on-first-failure` (records each first attempt, keeps it only when it fails; about the 8% e2e.yml notes for recording every test). Needs Eric's OK.
- The same subscribe-in-`useEffect` gap is in ~10 other places (`hooks.ts` `match.subscribe`, Duel, BossParty, SquadsParty, Home's party, App's squads/party/away subscriptions). Not changed here (match code): a follow-up.
