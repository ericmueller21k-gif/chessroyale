## Jefferson is now Grex (Eric, Nov 23)

Eric: "We can actually change his name to Grex everywhere, code can stay whatever it is but that's his new official name." The fireworks giraffe (roster id `grex`) is now **Grex** in everything a player reads. Spelling: Grex, never G-REX.

### What changed
- Player-visible copy: the roster name, the boss picker and boss bar, the battle intro and banners, his shop's sign ("Grex's Fireworks") and room and crate ("Grex's Boss Crate"), his sidekick's name ("Grex's sidekick"), the FAQ, the music theme's note, the token text.
- Code comments, docs in `docs/areas/`, `.claude/LESSONS.md` and test titles that said Jefferson or G-REX now say Grex.
- New decision note: `docs/decisions/2026-11-23-grex-name.md`.

### Kept on purpose
- Ids, file names, CSS classes, storage keys and database values: `grex`, `sidekick-jefferson`, `jefferson-giraffe`, `jefferson.ts`, `?boss=jefferson` (a test link alias, `BOSS_ALIASES`).
- The kit and character keys: `kit: "Jefferson"` in `BOSS_ROSTER`, `BOSS_KITS["Jefferson"]`, `POWER_MOMENTS`, `PORTRAITS`, `ch.name`. These are lookup keys, not copy. The screens show `boss.name` ("Grex"); `kitName` already maps the roster name to the kit, so the rename is one edit per roster entry.
- History: `docs/history/`, `DECISIONS.md` and older `docs/decisions/` files unchanged. Four notes that explain the old name keep "G-REX": `e2e/grex.spec.ts` (header and the "he was G-REX" test), `packages/app/test/grex.test.ts` (his name's describe), `packages/core/test/boss.test.ts` ("Grex was G-REX"), `docs/areas/bosses.md` ("G-REX until Oct 10").
