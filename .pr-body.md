**What's new**
- **The picture list, out of the renderer** (`town/pictures.ts`): every picture the town draws that is the same for everyone, with its
  name, its group and how it's painted. `render.ts` `plan` runs one job a want from it (`townWants`), so the device and the build read
  one list. The art behind the frame caches comes from it too; `BOSS_ART` lives there (re-exported).
- **`scripts/bake-town.ts`** (`npm run build` runs it; by hand `npx tsx scripts/bake-town.ts [out]`): paints the list in Node for a
  player's town and an admin's, packs each group's pictures into pages as the atlas packs, and writes content-named PNGs,
  `manifest.json` (each picture's file and place, roofs' and glows' pieces, frame times, box tops, the sidekicks' sheets) and
  `order.json` to `/town-pictures/`. It prints each file's pictures, pixels and bytes, and the totals.
- **Groups:** a home (frames, boss, glow, sides, roof), a street's row a side, the park, the Colosseum, the props, each sidekick's sheet
  as it is. What only one town draws is a file of its own (`.admin`, `.player`): no device fetches what it never draws.
