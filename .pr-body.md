## Fix main: the boss result's 16 px gap (Smudgy at 2.25), not #946's item animations

Main 888abe3e (e2e run 45621033897) had two [phone] retry-passes, both "16 px between the boss and your pawn" at 14.3125:
`e2e/boss-result.spec.ts:132` (a boss battle won) and `e2e/formats.spec.ts:174` (the Last Stand's result).

### Cause (with evidence)
- **Not #946.** I sampled every frame of the result row (the pawn's `.you-pawn-hop` box, its `.avatar` box, the hop's class and transform,
  the boss's painted edge). The pawn's box never changed: 122.4 px wide at x 221.81 in every frame, no hop (level 1, 100 XP), transform
  `none`. An SVG item animation can't change an HTML box anyway, and the e2e pawn wears no items.
- **It was Smudgy's defeat.** Across 12 random-boss runs, only Smudgy got under 16 px, at exactly **14.3125** (his painted right at 207.5,
  the pawn at 221.8125, `anim: defeat`). Every other boss stayed at 25 px or more.
- **Why it showed up now:** #944 (end screens 2) scaled the boss to 2.25x and set the row gap to a hand-tuned 48 px + 24 px padding.
  Smudgy's defeat reaches 1.7 px further than that leaves room for. The tests meet a random boss, so it failed about one run in twenty
  and landed on the next PR (#946). This same constant had gone stale for Smudgy at each scale change before (Nov 9: 12 px, Nov 11:
  5.6 px; styles.css's `.results-duo` comment).

### Fix (the cause: a number tuned by hand, met by chance)
- `ResultDuo` passes `--rd-reach`: how far right of his feet the boss is drawn in any figure the result shows (his idle, defeat and
  victory frames, from `drawnBox`, mirrored where his place turns him).
- `end-screen.css`: the row's gap is `max(48px, round(up, reach × k − box/2 − pawn art's inset + 16px))`, so every boss keeps 16 px by his
  drawing, at any scale. `--rd-bw` names the boss box's width (104; the Hidden Boss's 96) for the formula.
- `e2e/boss-result.spec.ts`'s victory test now meets **Smudgy** (`&boss=smudgy`), the boss nearest the pawn, so a stale gap fails every
  run instead of one in twenty. Proven: with the old CSS/TSX it fails at 14.3125; with the fix it passes.

### Player-visible changes
- Smudgy's end-screen row: 2 px wider (gap 50). Folio's: 4 px wider (gap 52; his quill in a result frame). Each row stays centered.
- Every other boss: unchanged (gap 48).
