**How**
- **The load** (`town/baked.ts`, `Town.tsx` `loadTown`): the manifest (named by its contents; the build hands the app the name,
  `__TOWN_PICTURES__`) and this town's pages are fetched, decoded off the main thread and uploaded whole, each placed on the atlas's
  layers (`paint-gl.ts` `adopt`, `placePages`). `render.ts` `plan` takes each picture by name; frame counts, roofs, glows and box tops come
  from the manifest (no animation built to count frames, no tops worked out, statues sculpted only if painted).
- **Kept:** the service worker answers a town file from any version's cache and copies them to a new version as it installs: a deploy
  fetches only changed groups (after a deploy: all 36 files in the new version's cache before the town opened). Home fetches them when idle.
- **Fallback (until phase 1c):** a file missing, `?paintall` or `TOWN_PICTURES.baked` off: the device paints as before. All or nothing.
