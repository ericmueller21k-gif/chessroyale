## main red: squads-replay.spec.ts:125 passed only on retry (Nov 23)

**Lane:** targeted (one app hook's timing; no rules, protocol or stored data).

**Cause (app, not the test).** `useMoveReplay` (`packages/app/src/screens/SquadsMatch.tsx`) redraws the board at each landing and at
the replay's end with a timer, picked inside a no-deps `useEffect`: "the next moment after now". Preact runs that effect a frame after
drawing (rAF, or a 35 ms fallback). If a lobby message redraws the screen just before the end and the frame comes after the end (a busy
device), the effect's cleanup clears the old end timer and finds no next moment, so none is set: the replay stays up until the next
lobby message. In Relay, when everyone else has moved, that can be seconds. Main's run 45230830938 (n = 2): the error-context snapshot
shows the free pill (its own 100 ms clock) at "free 1.4", 1.6 s past the replay's end, and the status line already back to normal a
moment later (the next redraw). The page was live; the board view just wasn't redrawn.

**Fix.** The next moment is picked at drawing time (the render's `now`), as the reveal's moments in the same file already are, and its
delay is clamped to 0, so a late effect redraws at once. 7 lines.

**Proof (local, wrangler dev, both projects).** A scratch copy of the spec (not committed) fires a client update 8 ms before the end,
lets the next frame land 1 ms after the end (a busy device), then holds other redraws for 3 s (Relay's quiet spell):
- before the fix: the overlay stayed up **3.0 s** past the end in 2 of 4 runs (phone and desktop): failed;
- after: **20 of 20 passed** (10 phone, 10 desktop), the overlay gone 4 to 23 ms after the end.
Plus the real spec, both tests, phone and desktop: 4/4; the first test under 6x CPU throttling (CDP), both projects: 6/6;
`packages/app/test/move-replay.test.ts`: 13/13; typecheck clean.

**Player-visible:** on a slow phone the replay no longer overruns its extra free time; otherwise nothing changes.

**Changed checks (old → new):** none. `e2e/squads-replay.spec.ts` guards Eric's "Squads: move replay" rule, so it was left as it was.

Decision: `docs/decisions/2026-11-23-squads-replay-end.md`. Lesson added to `.claude/LESSONS.md` (Nov 14's render-vs-effect entry).
