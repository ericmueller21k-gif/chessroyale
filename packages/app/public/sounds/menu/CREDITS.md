# Menu sounds

The God King's command menu. All from Juhani Junkala, *The Essential Retro Video Game Sound Effects Collection [512 sounds]* (CC0, https://opengameart.org/content/512-sound-effects-8-bit-style), loudness-matched.

| File | When | Source |
|---|---|---|
| open.mp3 | his menu opens | `sfx_menu_move2` |
| close.mp3 | his menu closes | `sfx_menu_move4`, pitched down |
| select.mp3 | you choose a command | `sfx_menu_select2` |
