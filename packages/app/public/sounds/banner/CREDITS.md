# Banner sounds

The fighting-game banners over the board. Swap either file for another with the same name to change it.

| File | When | Source (CC0) |
|---|---|---|
| start.mp3 | "START!" opens a boss battle | A synthesised whoosh with Juhani Junkala's `sfx_wpn_punch3` and `sfx_exp_short_hard3` (*The Essential Retro Video Game Sound Effects Collection [512 sounds]*) |
| boss-roar.mp3 | the boss's banner (it takes your queen) | HaelDB, *Male Grunt/Yelling sounds*, `yell5`, pitched down with a light crunch and echo, over Junkala's `sfx_exp_medium3` (low-passed) |
