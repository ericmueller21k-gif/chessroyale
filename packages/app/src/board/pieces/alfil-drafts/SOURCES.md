# Alfil's elephant piece: two drafts (not in the game)

Drafts for Eric to choose from (Oct 17, 2026). Nothing in the game draws them yet: no CSS, no wiring.
Each is a 45 x 45 SVG in the cburnett files' format (same outline weight 1.5, white `#ffffff` or black `#000000` fill,
black outline, details black on white and `#ececec` on black), so the chosen one can drop in beside them.

- `elephant-A-white.svg`, `elephant-A-black.svg`: an elephant's (mammoth's) head in profile, drawn for HunChess. Its
  base ribbon and collar are the cburnett bishop's own (`../cburnett/Chess_blt45.svg`, Colin M.L. Burnett, BSD: see
  `../LICENSE.txt`), so it stands like the bishop it moves like; the head, ear, trunk, tusk and forehead caparison
  (a nettipattam, as on Alfil's sprite) are new. Not traced from any other icon.
- `alfil-B-white.svg`, `alfil-B-black.svg`: the old abstract alfil, drawn for HunChess after the early Islamic
  (aniconic) chess pieces, whose elephant is a mound with two small knobs for tusks (for example the 12th-century
  Nishapur set at the Metropolitan Museum of Art, 1971.193a-ff). Stepped base and band after the reference Eric
  shared.
