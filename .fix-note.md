# Fix note: Dash's pop-off e2e flake (PR #560, CI run 42534985552, shard 10)

## Causes
1. **phone, `yourMove` saw "results"**: the test switch (`?power=popoff`) put the pop-offs on his turns 2 and 8, so the test
   played 8 moves of shuffled knights against Stockfish: long enough to get mated now and then.
2. **desktop, "Expected 6, Received 7"**: the failing line was 481 in CI's commit, `seen.cues["fit3:click"]` (the `rows at`
   check was the line above it). Scramble Rush can come from his turn 7, and its countdown smack is `fit3` too
   (`DashRush.tsx:307`), so an 8-move test sometimes counted one extra `fit3` click.
3. **found while proving the fix (phone, `fit10:click` 21, not 20)**: the test's counter counted every `data-cue` set.
   `BossCharacter` sets `data-cue` again whenever its drawn id changes on the same frame (his `look` or the lights), each time
   with the same `"click"`, so a smack was sometimes counted twice. No player-visible bug: the sound has its own guard
   (`played.has(s.tag)`), and the frames are the same.

## What changed
- `packages/chess/src/bosses/dash.ts`: `popOffTurns(…, "popoff")` returns `[2, 4]` (was `[2, 8]`). The real game's rule
  (two turns from 8 to 20, at least `gap` 6 apart) is unchanged.
- `e2e/dash.spec.ts`: the pop-off test plays 4 moves (was 8). The smack counter counts a click once each time an element
  enters a click frame (keyed by anim, frame and cue; reset by any other frame), not at every attribute set.

## Test checks, old → new
- `dash-clock.test.ts` "the test switch (?power=popoff)": `popAt` `[2, 8]` → `[2, 4]` (the title says fourth, not eighth).
- `dash.spec.ts` pop-off: `for 8 × playOne` → `for 4 × playOne`. Every assertion is unchanged (2 pops, 2 fast, counts 3/10,
  the timings, rows, `fit10:click` = 20, `fit3:click` = 6). The cue counter is stricter: re-sets of the same frame no
  longer count, but a real extra smack (a new click frame) still does.

## Proof (local)
- `npx playwright test e2e/dash.spec.ts -g "pop-off" --repeat-each 3` on both projects: 6/6 passed twice (12/12). Before the
  counter fix: 5/6 (the fit10 21).
- `npx vitest run packages/chess/test/dash-clock.test.ts`: 9/9. `npm run typecheck`: clean.
- Not touched: Scramble Rush code (#561). The `squads-three-boards` Relay failure in the same shard isn't this PR's.
