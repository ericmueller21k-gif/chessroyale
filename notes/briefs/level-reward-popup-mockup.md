# The level-up reward card: crate-style, centered, with "Go to inventory" — MOCKUP FIRST (Nov 22). Opus, high.
**Eric, Nov 22 (phone screenshot of the end screen's toast: "Level 4! +1 Winter Crate · +1 crate key / Daily reward: +1 Winter Crate", a plain light card at the top over "XP EARNED"):** "this crate reward thing, I think we need to make that more in the color scheme, or like the UI scheme of like what it normally looks like when you open a crate, like so that you either using that blue background style, like that video game style, and put it more, when you actually get an unlock, it should be more in the center of the screens, and it should pop more, so like it feels a bit better. And then it should have like an OK, or ... show in inventory basically, or go to inventory ... But then it shouldn't, you know, if whatever you're in, like if you back out, we just need to make sure that there's a save state, like if you did that when you're in like the battle tower, for example. But the problem is, like, if you were doing the battle tower with like 4 people, then I guess you can't really save. So I guess maybe in the battle tower we don't, or like if you're in a party, because we don't want you backing out of the party to go to your inventory, so I'm not sure how we handle that, to be honest."
- The card (components/RewardBox.tsx and the end screen, components/EndScreen.tsx) restyled in the crate opening's look (the blue video-game panel the crate screens use: reuse those styles), centered on screen, with a pop-in (reuse an existing pop animation), the prize icons bigger.
- Buttons: **OK** (closes it) and **Go to inventory**. The director's proposal for Eric's question (in the .mockup note for him to confirm): "Go to inventory" is shown always (nothing hidden) but greyed with a short reason ("After your run" / "After the party") while you're in a Battle Tower run or a party, since leaving would drop you out; anywhere else it opens your inventory and Back returns to where you were (home / town). The prizes are already in your inventory either way.
- Mockup only first (no PR): phone and computer stills, OK + enabled inventory button, and the greyed one in a tower run; a short clip of the pop. Stills on `stills/level-reward-popup`, `.mockup` note on `claude/level-reward-popup`. Base on main.
