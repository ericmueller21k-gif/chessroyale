# CI fix: home-ranked.spec.ts "the Boss raid screen" (People only), run 42680461097 shard 2

## Cause (not L1's code)
The failed run's trace: "Join a raid" posted `/api/play?mode=raid&pool=raidscreen-desktop-…`, but "People only" right after
its Cancel posted `/api/play?mode=raid&type=botsoff` with **no `pool`**, and got a 500 after 1.5 s (wrangler: "POST
/api/play?mode=raid&type=botsoff … Network connection lost"), so the queue screen never opened. The queue's Cancel runs App's
`leave()`, which does `history.replaceState(null, "", "/")`, and `testParams()` reads the live address. So every PLAY after
leaving a queue lost `?pool=` and joined the server's shared raid queue (the same for Crowd's PLAY, "let bots fill" and
Squads' queue and party). It passed or failed depending on what other tests on the shard had left in that shared queue.
That's why it moved with the shard layout and passed 40 of 40 alone. The same code is on main; the PR's changes don't touch
this path (the diff since the green run 399b5c5 is the 1 v 1 room's `noShowAt` and docs).

## Fix
`queuePool()` (packages/app/src/test-switches.ts): `?pool=` from the address now, else the one the page opened with (read once,
as `TOWN_ASKED` already does for `?crowd`), and only where test switches count. All four queue readers use it: App's `playNow`
and `letBotsFill`, and squads.ts' `squadsQueue` and `createParty`. Players are unaffected: test switches never count for them.

## Tests
- e2e (tightened, not loosened): home-ranked.spec.ts "the Boss raid screen" now checks that People only's request carries
  the test's own pool. Before the fix it fails every time (`Expected "raidscreen-desktop-…"`, `Received null`). After the fix,
  `--repeat-each 10` on phone and desktop: 20 of 20 pass.
- Unit: test-switches.test.ts "?pool= (a queue of its own)": kept after the address drops it, the address's own wins, null
  without test switches. packages/app/test: 159 files, 2252 tests pass. Typecheck clean.
- Changed checks: one added in home-ranked.spec.ts (above); none removed.
